# 🧠 DeepTrace AI v2.0
### AI-Powered Digital Media Forensics & Source Tracking System

DeepTrace AI is a professional-grade digital forensic workstation designed to detect image manipulation, analyze pixel-level compression artifacts, and trace evidence origins.

## 🚀 Features
- **Cinematic Forensic UI:** Immersive "Cyber OS" experience built with Flask/HTML/CSS.
- **Error Level Analysis (ELA):** Detects localized re-compression inconsistencies.
- **Dynamic Scoring:** Heuristic math engine based on pixel variance and metadata integrity.
- **Evidence Preservation:** Real-time generation of MD5 and SHA-256 digital signatures.
- **Forensic Reporting:** Automated generation of downloadable PDF investigation reports.
- **OSINT Intelligence:** Integrated bridges to TinEye and Google Lens for source tracing.

## 🛠️ Tech Stack
- **Backend:** Python / Flask
- **Image Processing:** OpenCV, Pillow, NumPy
- **Reporting:** FPDF2
- **Frontend:** HTML5, CSS3 (Glassmorphism), JavaScript (AJAX)

## 📦 Installation
1. Clone the repo: `git clone https://github.com/Sreya-Shyjash/DeepTrace-AI.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the server: `python app.py`
4. Access at: `http://127.0.0.1:8501`
